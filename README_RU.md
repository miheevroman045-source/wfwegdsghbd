# Ultra Enchant 10000 — Fabric для Minecraft Java 1.20.1

Позволяет наложить любые существующие зачарования на ЛЮБОЙ предмет уровнем 1–10000. Дополнительно реализован веерный мультивыстрел для стандартных метательных снарядов (снежки, яйца, зелья, жемчуг Эндера, пузырьки опыта, стрелы, трезубцы).

## Команды

Включите читы или используйте учётную запись оператора. Возьмите нужный предмет в ОСНОВНУЮ руку:

- `/ue add minecraft:multishot 10000` — зачаровать предмет на Мультивыстрел 10000
- `/ue add minecraft:sharpness 10000` — Острота 10000 на любом предмете
- `/ue add minecraft:power 10000` — Сила 10000
- `/ue all 10000` — все чары сразу 10000 (включая проклятия; осторожно)
- `/ue clear` — удалить все чары с предмета

## Ограничения

В записи чар уровень может быть 10000, но ванильные эффекты не всегда масштабируются по уровню: например, сам «Мультивыстрел» в Minecraft не выпускает 10000 снарядов. Мод даёт собственный веер выстрелов: максимум 33 снаряда за применение, чтобы не повредить миру лагами. Предел меняется константой `MAX_REAL_SHOTS` в Java-коде.

Некоторые бессмысленные для предмета чары просто отображаются, но не действуют (например, подводная скорость на палке). Не рекомендуется применять `/ue all 10000` к предметам для обычной игры. Некоторые экстремальные уровни зачарований могут вызывать необычное поведение в Minecraft.

## Сборка на Windows

1. Установите JDK 17 или новее и Gradle 8.12.1 (или откройте проект как Gradle-проект в IntelliJ IDEA).
2. В папке проекта выполните `gradle build`.
3. Готовый мод будет в `build/libs/ultraenchant-1.0.0.jar` — НЕ `-sources.jar`.
4. Установите Fabric Loader для Minecraft 1.20.1 и Fabric API 0.92.2+1.20.1.
5. Положите jar мода и Fabric API в `.minecraft/mods`, запустите профиль Fabric **1.20.1**.

Для 26.3 этот проект не совместим: потребуется отдельная версия под изменённые API и систему зачарований 26.x.

## Важно

Исходники подготовлены, но JAR в этой среде не собран: загрузка зависимостей с внешних серверов недоступна. Не выдавайте исходный ZIP за готовый мод для папки mods.
